📖 Miniguia de Estudo
🔹 Estruturas Condicionais

As estruturas condicionais são usadas para tomada de decisão.

Exemplo:

idade = 18

if idade >= 18:
    print("Maior de idade")
🔹 Estruturas de Repetição
For

O for é utilizado quando sabemos quantas vezes o laço será executado.

for i in range(5):
    print(i)
While

O while executa enquanto a condição for verdadeira.

numero = 0

while numero < 5:
    print(numero)
    numero += 1
📚 Glossário
Termo	Significado
if	Estrutura de decisão
for	Laço de repetição
while	Estrutura de repetição condicional
break	Interrompe o laço
continue	Pula uma repetição
range()	Gera sequência numérica
