# miniguia-estudos-notebooklm
Caderno temático sobre Python para iniciantes utilizando NotebookLM e Inteligência Artificial como apoio aos estudos.

📘 Caderno Temático — Python para Iniciantes com NotebookLM
📌 Contexto do Projeto

Este projeto foi desenvolvido como desafio prático da DIO utilizando o NotebookLM como ferramenta de apoio aos estudos.

O tema escolhido foi Python para Iniciantes, com foco em:

Estruturas condicionais;
Estruturas de repetição;
Comandos break e continue;
Lógica de programação básica.
🎯 Objetivos de Estudo
Aprender lógica de programação com Python;
Entender o funcionamento do if, for e while;
Praticar estruturas de repetição;
Utilizar IA como ferramenta de aprendizagem ativa;
Criar um material reutilizável para revisões futuras.
